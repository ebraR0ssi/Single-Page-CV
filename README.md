# A single page cv project.

## The first project in the frontend roadmap in roadmap.sh.

The project consists of only a single page of plain HTML and a little bit of styling using CSS. There are four section:

- The intro is where you can find my basic info, including my name, location, phone, and an email address (The email address in the project is a demo one, so place don't sent anything to it).
- You got the skill set. In this section you will find some of the skills that I have as a beginner. Although I have more skills that what is shown, but for the sake of the project, I have followed the instruction. literally.
- The in the education section, you will find a brief information and explanation of my academic study, including the university, the degree I took, etc.
- Last but not least, there is the experience section. I still don't have a real world experience when it comes to the tech industry, so the company you will see in the project is just an example. I didn't work there.
- In footer you will find two links, one for LinkedIn - I also don't have a LinkedIn profile, so the link will lead you straight to the actual page of LinkedIn. You also got my GitHub account, this one is real, and will load my GitHub account in a separate tab.
